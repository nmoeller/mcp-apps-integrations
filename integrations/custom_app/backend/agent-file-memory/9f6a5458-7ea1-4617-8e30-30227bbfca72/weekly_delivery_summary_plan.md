# Weekly Delivery Summary Plan

- Scope: weekly delivery summary for the week ending Sunday, September 20, 2026.
- Source: current coworker dataset returned by `get_mock_data`.
- Outputs:
  1. Bar chart of tasks completed by coworker.
  2. Line chart of tasks completed by coworker.
  3. Pie chart showing each coworker’s share of completed tasks.
  4. Text stating who completed the most tasks and the team total.
- Constraint: Use only returned values; do not infer productivity or performance from task counts.
